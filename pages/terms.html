2 Service Purpose & AI Audio Processing

Zoom Meeting Dock is a client-side assistive productivity tool designed to capture meeting dialogue from authorized sources (such as active browser tabs and microphone inputs) to produce live transcripts, generate synchronized playback, and organize action items.

  • Speech-to-Text Services: Audio transcription is executed via Gnani.ai / Vachana.ai STT API endpoints using the API credentials configured by you.
  • Local Audio Streaming: Audio processing occurs on-device using Web Audio API nodes. Tab audio capture requires explicit user consent through the browser screen/tab sharing selector.
